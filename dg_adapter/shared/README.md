# Gemeinsame DG-/HEO-Regeln

Hier liegen nur Module, die mehrere Bereiche des Adapters oder die Oberfläche
gemeinsam verwenden.

| Modul | Aufgabe |
| --- | --- |
| `dg_paths.py` | Verbindliche Pfade für Szenario-Eingaben und Ergebnisse |
| `scenario_names.py` | Szenarionamen für DG und Dateisystem validieren |
| `comparison_contract.py` | Varianten, Manifestversion und Vergleichsfehler definieren |
| `device_catalog.py` | HEO-Gerätemetadaten an der Adaptergrenze auf DG-Codes abbilden |
| `building_supply.py` | Regeln für Gebäudeversorgung und Anschlussprüfung |
